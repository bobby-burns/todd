TikTok Sans (https://github.com/tiktok/TikTokSans, from Google Fonts), SIL Open Font License 1.1 (OFL.txt): the
typeface of TikTok's own on-screen text, so a short's text and captions look like they were typed in the app.

Static instances of the variable font (wght 600 and 800, opsz 36, wdth 100, slnt 0), made with fontTools:
`instancer.instantiateVariableFont(font, {"wght": 600, "opsz": 36, "slnt": 0, "wdth": 100}, updateFontNames=True)`.
